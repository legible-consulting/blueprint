# Workshop kit

The one-day ICM workshop: the method in the morning, the walk in the afternoon. Attendees read
it from here. Nothing in this folder is client-specific.

| File | Is |
|---|---|
| `slides.md` | the day, as Marp slides: seven hours, five words (the desk, the stage, the contract, the map, the gate) |
| `exercises.md` | one exercise per hour, each with a goal, the steps, what the attendee leaves with, and a check |
| `walk-test.md` | the nine checks an attendee's workspace must pass, with a sign-off line |

Show the slides with Marp: `marp workshop-kit/slides.md`, or the Marp extension for VS Code.

The afternoon starts from a three-stage workspace. Render it from this blueprint with
`copier copy gh:legible-consulting/blueprint <folder> --data workspace=true`, or make the same
folders by hand. A coaching client gets the same render for their own job, and the coaching
hours run the walk test on it again.

A longer engagement (several mornings, coaching in the afternoons) keeps the order of this day
and spends more time per hour. The method rests on Jake Van Clief's Foundation course in
`legible-consulting/library` (read only). Each file names the lessons it rests on and quotes
at most one line of the course.
