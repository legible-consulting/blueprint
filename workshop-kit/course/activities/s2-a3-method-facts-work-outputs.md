# S2 A3 — Method, facts, work, outputs

Session 2 · 25 minutes · pairs

## You need

- The printed file list of the example's messy folder. The facilitator hands it out. The
  roles of the files are in `../example/README.md`.
- Four columns on a page: method, facts, work, outputs.

## Steps

1. Read each file name. Open the file when the name does not say enough.
2. Put each file in one column.
   - Method: how the business does a kind of job. It would travel to another business.
   - Facts: true of this business only. Prices, hours, names.
   - Work: in progress now.
   - Outputs: what left, or is ready to leave.
3. A file that fits no column goes below the table.
4. For each file below the table, write one word: delete, merge or archive.
5. Agree the table with your pair. Where you disagree, write both views.

## Write down

- The table.
- The files below it, with their one word.

## Test for a hard case

- Ask: "Would this file change if a new customer walked in?" No means method.
