# S5 A6 — The walk test

Session 5 · 20 minutes · pairs

## You need

- Your folder.
- `../walk-test.md`, printed, one copy per attendee.
- A second tool or model for item 11, or the facilitator's.

## Steps

1. Your pair holds the test and records. You run the folder.
2. Follow "Before you start" in the test.
3. Run items 1 to 11 in order.
4. For each item, your pair writes pass or fail and the evidence they saw.
5. For each fail, write the fix under it.
6. Swap roles if time allows.

## Write down

- The record table, complete.
- The fixes.

## Leave with

- A folder that passed, or the list of failed items and their fixes.
