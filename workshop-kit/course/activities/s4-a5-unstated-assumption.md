# S4 A5 — A new request with an unstated assumption

Session 4 · 10 minutes · pairs, after the facilitator's demonstration

## You need

- An unpacked copy of `example/ordered/`.
- The example's first request. The path is in `../example/README.md`.

## Steps

1. Open the ordered folder in your tool.
2. Type the first request in one line.
3. Read the draft.
4. Find the place where the draft names the assumption, or asks the owner one question.
5. Open the map and the contract. Find the line that made it do so.
6. If the draft guessed instead: name the file that should have carried the fact. Check
   whether the routing row opens it.

## Write down

- The sentence in the draft that names the assumption or asks.
- The line in the map or contract behind it.
