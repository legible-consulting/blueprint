# S3 A1 — Open the messy folder and watch

Session 3 · 20 minutes · alone

## You need

- Your own unpacked copy of `example/messy/`. Never the facilitator's copy.
- A tool that reads a folder, with the permission mode set to ask before edits and runs.
- The example's first request. The path is in `../example/README.md`.

## Steps

1. Open the folder in the tool.
2. Type the first request in one line.
3. Watch the tool. Write down every file it opens, in order.
4. Do not answer any question it asks. Write the question down instead.
5. Read the reply. Find the price it used.
6. Find the file that price came from.

## Write down

- The list of files opened.
- The question it asked, if any.
- The price it used and the file it came from.
- One file it opened that it should not have.
