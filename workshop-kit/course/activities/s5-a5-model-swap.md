# S5 A5 — The model swap

Session 5 · 10 minutes · alone, or watching the facilitator

## You need

- Your folder.
- A second model, or a second tool that reads folders. The facilitator has one.

## Steps

1. Note the name of the map file your first tool reads.
2. If the second tool reads another name, copy the map to that name. Change nothing inside.
3. Open the folder in the second tool, or point the second model at it.
4. Type the same request as walk test item 2.
5. Write down the files it opens and where the output lands.
6. Compare with your item 2 record.

## Write down

- Same files, yes or no.
- Same output place, yes or no.
- Anything you changed other than the map's file name. The answer should be "nothing".
