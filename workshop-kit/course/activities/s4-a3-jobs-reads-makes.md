# S4 A3 — Jobs, reads and makes, four piles, one label

Session 4 · 25 minutes · alone

## You need

- The copy of your real folder.
- A page with three sections: jobs, piles, labels.

## Steps

1. List the jobs that lead to the outcome. One line each.
2. For each job, write what it reads and what it makes. Name files.
3. Sort every file in the folder into four piles: method, facts, work, outputs. Use the
   test from S2 A3.
4. Label each file: instructions, state, or both.
   - Instructions: tells the assistant or a person what to do.
   - State: something the job reads and changes.
5. Circle every file that is neither instructions nor state.
6. For each circled file, write one word: delete, merge or archive.

## Write down

- The three sections, complete.
- The circled files and their one word.

## Remember

- A file that is neither is the first suspect. It is often a summary of another file.
