# S3 A2 — Draft the map, add one row

Session 3 · 35 minutes · alone, then pairs

## You need

- The folder and tool from S3 A1.
- The list of files opened from S3 A1.

## Steps

1. Type: "Draft a map for this folder as a file at the top. Four parts: purpose, layout,
   naming, routing table. One screen."
2. Open the file it wrote.
3. Cut it to one screen. Keep purpose, layout and naming short.
4. In the routing table, keep one row: the first request. The row names:
   - the files to open
   - the files to leave shut
   - the written process to apply, if any
   - where the output goes
5. Save the map under the name your tool reads. Claude Code reads `CLAUDE.md`. Codex reads
   `AGENTS.md`. Checked on 2026-10-25.
6. Close the session.
7. Open a new session on the same folder.
8. Type the first request again.
9. Write down every file it opens.
10. Compare with S3 A1. Count the files.
11. Show your pair the row. Ask them to name one file the row forgot.

## Write down

- The row.
- The number of files opened before and after.
- The price the new reply used.

## Pass

- Three files or fewer opened. Each one named in the row.
