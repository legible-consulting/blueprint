# S2 A1 — From corrections to a written process

Session 2 · 35 minutes · alone, then pairs

## You need

- Your corrections log from session 1.
- A chat window.

## Steps

1. Open a new chat.
2. Type: "Write a skill for the job below. Interview me first, one question at a time." Then
   describe the job in two sentences.
3. Paste the corrections log.
4. Answer each question. Expect: what the job is for, what triggers it, one good example.
5. Save the file it produces. Name it after the job.
6. Read the file as an editor. For each step, find the correction it came from.
7. Strike every line that has no correction behind it.
8. Strike every line that turns one example into a rule for all cases.
9. Paste the edited file back. Type: "Rewrite from my edits. Add nothing."
10. Read the result once more.
11. Show your pair the when-to-use line. Ask them to say, in one sentence, when it fires.

## Write down

- The lines you struck in steps 7 and 8.
- The when-to-use line, final.

## Bring

- The file to S2 A2.
