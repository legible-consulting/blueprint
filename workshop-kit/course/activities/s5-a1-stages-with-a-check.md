# S5 A1 — Stages with a human check

Session 5 · 25 minutes · alone, then pairs

## You need

- Your folder from session 4.
- One page per stage.

## Steps

1. Write your job as stages. Each stage ends with one file. Example: gather, draft, check,
   send.
2. For each stage, write the contract with four parts: Input, Do, Output, Human check.
3. Put the Human check of the first stage where the first error can appear.
4. Mark the one or two stages where your taste changes the result.
5. Leave the scripted stages unmarked.
6. Read the stages to your pair. Ask: "Which marked stage would you skip with five minutes?"
7. Unmark that one if you agree.

## Write down

- The stages, in order, each with its output file.
- The marked stages.

## Test

- Each stage names one output. No two stages write the same file.
