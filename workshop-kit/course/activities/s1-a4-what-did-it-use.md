# S1 A4 — What did it use

Session 1 · 20 minutes · alone

## You need

- The chat from S1 A3.

## Steps

1. Type: "List every source you used for the last reply. Name each one."
2. Read the list.
3. For each item, open the material you pasted and find it.
4. Mark each item: pasted, or not pasted.
5. For each item marked "not pasted", write down what the assistant filled in and from where
   it may have come.
6. Type: "Which of those did I not give you?"
7. Compare its answer with your marks.

## Write down

- The number of items marked "not pasted".
- One line: what you will put on the desk next time so that number is zero.

## Remember

- A claim of use is not use. Stored is not active. Look.
