# S2 A2 — The fresh-chat test

Session 2 · 15 minutes · alone

## You need

- The written process from S2 A1, installed in your assistant. The facilitator shows the
  install step for the day's tool.

## Steps

1. Close every chat.
2. Open a new chat.
3. Type one line that asks for the job. Use words a colleague would use, not the file's name.
4. Read the first lines of the reply. Find the line where it names the process it is using.
5. If it names the process: read the reply against the steps in your file. Mark each step
   followed or skipped.
6. If it does not name the process: read your when-to-use line aloud. Change the line, not
   your request. Repeat from step 1.

## Write down

- Pass or fail on the first try.
- The when-to-use line, if you changed it, before and after.
