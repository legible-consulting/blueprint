# S5 A2 — One steady step into a tool

Session 5 · 25 minutes · alone

## You need

- Your folder, open in your tool.
- One result of the step, made by hand earlier. A total, a list, a table.

## Steps

1. Pick one step that passes the test: done the same way three or four times, and the right
   answer does not depend on taste.
2. Type: "Write a script in a tools folder for this step. One input file, one output file.
   It stops when done." Describe the step.
3. Read the script. Ask the assistant to explain any line you do not understand.
4. Run the script on the same input you used by hand.
5. Compare the two results line by line.
6. If they differ, find the difference and fix the script or the hand result.
7. Add one line to the map: the script's name and when to run it.

## Write down

- The step.
- Match or no match, and the difference if any.
- The map line.

## Do not

- Do not let the script start the next stage. If it does, cut that line.
