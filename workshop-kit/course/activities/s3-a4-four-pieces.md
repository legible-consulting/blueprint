# S3 A4 — The four pieces

Session 3 · 20 minutes · alone

## You need

- Your own setup, as you use it today.
- An empty folder with one text file in it. Any file of one page.

## Steps

1. Name the four pieces of your setup:
   - the model
   - the harness, the app that gives it file and run access
   - the interface you type into
   - where it runs: cloud, your machine, or both
2. Name one switch you may make this year.
3. Say which single piece the switch changes. If it changes two, write both.
4. Say whether the switch keeps your files local, runs the model locally, both or neither.
5. List the whole cost of your setup: subscription, setup time, upkeep, checking output,
   waiting.
6. Run the tiny test. Open the empty folder in your tool. Type: "Write a one-page summary of
   this file and save it next to it."
7. Close the tool. Open the summary in a plain text editor.

## Write down

- The four pieces.
- The switch and the piece it changes.
- Whether the summary opened outside the tool.
