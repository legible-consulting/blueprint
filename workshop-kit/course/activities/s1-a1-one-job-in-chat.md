# S1 A1 — One job in a fresh chat

Session 1 · 20 minutes · pairs

## You need

- A chat window, with no other chat open.
- The example's first request: the request with the unstated assumption. The path is in
  `../example/README.md`.
- The example's facts file for that request, named on the same page.

## Steps

1. Open a new chat.
2. Paste the request.
3. Paste the facts file under it.
4. Type: "Reply to this customer."
5. Read the reply once, as the customer would.
6. Circle every sentence that promises or assumes something the pasted material did not say.
7. Show the circled sentences to your pair.

## Write down

- The sentence you circled first.
- The word in your request that opened the gap. If there is none, write "none".

## Do not

- Do not add detail to the request before step 5. The gap is the lesson.
- Do not reuse a chat from another job.
