# S1 A3 — The fact the prose cannot fix

Session 1 · 25 minutes · alone, after the facilitator's demonstration

## You need

- A new chat.
- The example's second request: the request that needs a fact from the diary. The path is
  in `../example/README.md`.
- The example's diary file, named on the same page. Do not paste it yet.

## Steps

1. Paste the request only.
2. Type: "Reply to this customer."
3. Find the sentence that promises a slot, a date or an item.
4. Try to fix that sentence by rewriting it. Spend at most five minutes.
5. Stop. Write down the fact the sentence needs.
6. Write down the file where that fact lives.
7. Paste the diary file.
8. Type: "Reply again, using the diary."
9. Read the new reply. Mark whether the promise is now right.

## Write down

- The fact.
- Its home.
- One line: why the rewrite in step 4 could not fix it.

## Do not

- Do not write "please check availability" into the reply and call it fixed. That moves the
  fact to a person who was not named.
